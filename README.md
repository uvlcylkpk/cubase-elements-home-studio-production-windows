## Quick Start for Cubase Elements on Windows

1. Install Cubase Elements from the official Steinberg source.
2. Open Studio Setup and choose your ASIO audio driver.
3. Set sample rate to 44.1 kHz or 48 kHz based on your project target.
4. Create a template with audio, MIDI, and FX return tracks.
5. Record a short audio take and test MIDI latency.
6. Save this template as your default Cubase Elements session.

This fast setup creates a repeatable **Cubase Elements recording template** and avoids common beginner mistakes in driver routing and buffer configuration.
